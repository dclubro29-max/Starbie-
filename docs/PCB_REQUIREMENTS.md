# Starbie PCB requirements (draft)

## Functional requirements
- FR-01: Display a clock/status/settings UI on a circular screen.
- FR-02: Two physical buttons navigate modes and select options.
- FR-03: Accept a stable regulated supply within component ratings.
- FR-04: Expose programming/debug access for the selected MCU.
- FR-05: Keep connector pinouts and polarity documented.

## Acceptance criteria (not yet met)
- Exact part numbers, footprints and pin mapping recorded
- Schematic reviewed against datasheets
- KiCad ERC and DRC outputs saved from actual runs
- Prototype demonstrates screen output and button input
- Measured supply current and thermal behavior documented

## Risks
- Incompatible LCD logic voltage
- Backlight overcurrent
- Incorrect USB or regulator wiring
- Footprint mismatch
- Mechanical interference with circular enclosure

This is a requirements specification, not evidence of completed hardware.
