# Half Life submission readiness checklist

This checklist is a planning aid, not an official guarantee of approval.

- [ ] Review the current official Half Life theme and submission rules
- [ ] Confirm project is submitted under the correct week and theme
- [ ] Show original, editable project files relevant to the theme
- [ ] Provide authentic screenshots or a real walkthrough video
- [ ] Link relevant GitHub commits and describe personal contributions
- [ ] Verify logged hours match time actually worked
- [ ] Provide accurate BOM and project status
- [ ] Include a working demonstration if required by the current checkpoint
- [ ] Resolve reviewer comments and resubmit when permitted

**Printer reward:** The official Half Life homepage describes a 3D printer for completing all ten weeks, not a guaranteed specific model for one submission. Model selection, upgrades and fulfillment depend on program rules and review outcomes.
